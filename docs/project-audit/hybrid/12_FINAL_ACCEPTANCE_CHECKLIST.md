## 2. Non-Functional, Security & Localization Sign-Off | تایید الزامات غیرکارکردی، امنیتی و بومی‌سازی

### Security & Access Control | امنیت و کنترل دسترسی
- [x] رمزهای عبور با الگوریتم سالت‌شده Argon2id هش و ذخیره می‌شوند.
- [x] توکن‌های دسترسی (JWT Access Token) صرفاً در حافظه رم مرورگر نگهداری می‌شوند (بدون ذخیره‌سازی در `localStorage` یا `sessionStorage`).
- [x] توکن‌های رفرش از طریق کوکی‌های امن با مشخصات `HttpOnly`, `SameSite=Lax` و مکانیزم چرخش خانواده توکن (Family Rotation) منتقل می‌شوند.
- [x] ایزولاسیون کامل چندمستاجری (Multi-Tenancy) از طریق درج الزامی فیلتر `organizationId` در تمام کوئری‌های دیتابیس اعمال شده است.
- [x] محدودیت دسترسی کارشناسان فروش صرفاً به سرنخ‌های اختصاص‌یافته (`assignedToId = user.id`) در لایه سرویس تضمین شده است.
- [x] نقش کارفرما (Client) به‌طور قطعی از ارسال درخواست‌های تغییردهنده (Mutation) برای کمپین‌ها، هزینه‌ها و بارگذاری فایل محروم است.
- [x] شماره‌های موبایل برای نقش‌های غیرمجاز به فرمت `0912***4567` ماسک می‌شوند.
- [x] کلیه کوئری‌های پایگاه‌داده از طریق Prisma ORM پارامتریزه شده و در برابر تزریق SQL (SQL Injection) مصون هستند.
- [ ] تنظیم هدرهای امنیتی وب توسط Helmet در بوت‌استرپ فریم‌ورک NestJS. *(زمان‌بندی شده در فاز `PHASE-010`)*
- [ ] فعال‌سازی محدودیت نرخ درخواست (Rate Limiting / Throttler) روی اندپوینت‌های ورود و رفرش توکن. *(زمان‌بندی شده در فاز `PHASE-010`)*

### Persian RTL & Iranian Localization | بومی‌سازی زبان فارسی، تقویم جلالی و چیدمان راست‌به‌چپ
- [x] ساختار پایه HTML با ویژگی‌های `<html lang="fa" dir="rtl">` تنظیم شده است.
- [x] قلم محلی وزیرمتن (Vazirmatn) با تمامی وزن‌ها از نازک تا سیاه بارگذاری شده است.
- [x] موتور محاسباتی مستقل تقویم جلالی در بازه ۱۱٬۳۲۳ روز پیاپی (۱۳۹۰ تا ۱۴۲۰) راستی‌آزمایی گردید.
