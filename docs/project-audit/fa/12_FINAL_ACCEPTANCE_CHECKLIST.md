## ۱. چک‌لیست تحویل صفحات و قابلیت‌های محصول (۲۹ از ۲۹ صفحه)

### صفحات عمومی (صفحات ۱ تا ۳)
- [x] **صفحه ۱: ورود و انتخاب سازمان (`/login`, `/select-org`):** کارت وسط‌چین، دکمه نمایش رمز، ورود با ایمیل/موبایل، کارت‌های انتخاب سازمان با نقش، چرخش رفرش‌توکن.
- [x] **صفحه ۲: صفحه خانه نقش‌محور (`/`):** شبکه ۱۲ ستونی ویجت‌ها، استقلال خطا/لودینگ هر ویجت، ۵ نمای مجزا برای کارفرما، مدیر، کمپین‌چی، فروش، تولید محتوا.
- [ ] **صفحه ۳: مرکز اعلان‌ها (`/notifications`):** کشوی ۱۰ اعلان آخر هدر؛ صفحه کامل با لیست اعلان‌ها و تب ماتریس تنظیمات اعلان؛ شمارنده با سقف `+۹۹`. *(برنامه‌ریزی‌شده در فاز ۲)*

### فضای کاری ۱: عملکرد (صفحات ۴ تا ۱۳)
- [x] **صفحه ۴: داشبورد اجرایی (`/performance/dashboard`):** ۶ کارت شاخص، نمودارهای هماهنگ هزینه و لید، قیف تبدیل، سهم پلتفرم، جدول خلاصه کمپین‌ها، پنل هشدارها با دکمه ساخت تسک.
- [x] **صفحه ۵: لیست کمپین‌ها (`/performance/campaigns`):** جدول کمپین‌ها، نشان‌های وضعیت، نوار مصرف بودجه، منوی عملیات سطر (کپی، توقف/ادامه، بایگانی)، نوار فیلترها.
- [x] **صفحه ۶: ویزارد ساخت کمپین (`/performance/campaigns/new`):** ویزارد ۶ مرحله‌ای، انتخاب مخاطب، جدول بودجه پلتفرم، شاخص‌های هدف، سازنده UTM، ذخیره خودکار ۳۰ ثانیه‌ای.
- [x] **صفحه ۷: جزئیات کمپین (`/performance/campaigns/:id`):** هدر ثابت با عملیات، ماندگاری تب فعال در آدرس مرورگر، ۸ تب جزئیات (خلاصه، پلتفرم، لیدها، لندینگ، پیامک، تقویم/تجهیزات، تسک‌ها، تحلیل).
- [x] **صفحه ۸: مدیریت پلتفرم‌ها (`/performance/platforms`):** جدول پلتفرم‌ها، قالب‌های پیش‌فرض، کشوی ورودی‌ها و خروجی‌ها، هشدار غیرفعالسازی در صورت استفاده در کمپین‌ها.
- [x] **صفحه ۹: ثبت و رهگیری هزینه‌ها (`/performance/costs`):** نوار خلاصه هزینه، جدول هزینه‌ها، کشوی ثبت سریع با پاک شدن خودکار مبلغ، جدول ثبت دسته‌ای با امکان Paste از اکسل.
- [x] **صفحه ۱۰: ایمپورت داده‌ها (`/performance/imports`):** جدول تاریخچه ایمپورت، ویزارد ۴ مرحله‌ای (انتخاب فایل، نگاشت فیلدها، پیش‌نمایش ۲۰ سطر با خطاها، نتیجه نهایی)، دانلود فایل نمونه.
- [x] **صفحه ۱۱: شاخص‌ها و فرمول‌ها (`/performance/kpis`):** جدول KPIها، فرمول‌ساز تعاملی با متغیرها و کلیدهای عملگر، اعتبارسنجی فارسی فرمول، جمله‌ساز قواعد هشدار.
- [x] **صفحه ۱۲: مخاطبان هدف (`/performance/audiences`):** نمای کارتی/جدول، مشخصات دموگرافیک، جدول کمپین‌های مصرف‌کننده مخاطب، منع حذف مخاطب استفاده‌شده.
- [x] **صفحه ۱۳: لندینگ و UTM (`/performance/landing`):** جدول لندینگ‌ها با هشدار ۳۰ روز بدون لید، سازنده زنده لینک UTM با پیش‌نمایش، تاریخچه لینک‌ها، راهنمای Google Ads و GA4.

### فضای کاری ۲: فروش و لید (صفحات ۱۴ تا ۱۸)
- [x] **صفحه ۱۴: صندوق ورودی لیدها (`/leads`):** جدول لیدها، ماسک شماره موبایل (`۰۹۱۲***۴۵۶۷`) با دکمه تماس، تخصیص گروهی، تغییر وضعیت گروهی، اخطار تکراری، نمای کارتی موبایل.
- [x] **صفحه ۱۵: برد کانبان پیگیری لید (`/leads/board`):** ۶ ستون افقی، کارت‌های قابل کشیدن با تاریخ پیگیری، به‌روزرسانی خوش‌بینانه، مودال دلیل رد در «ردشده»، مودال مبلغ در «مشتری».
- [x] **صفحه ۱۶: جزئیات و مسیر لید (`/leads/:id`):** نوار خلاصه سفر، چیدمان دو ستونی مشخصات و خط زمانی، فرم ثابت ثبت تماس بالای خط زمانی، ثبت یادداشت و یادآور.
- [x] **صفحه ۱۷: ارسال پیامک (`/leads/sms`):** لیست ارسال‌ها، صفحه جزئیات با آمار تحویل و شکست، جدول شماره‌ها با متن پاسخ، ایمپورت نتیجه ارسال و تبدیل پاسخ به لید.
- [x] **صفحه ۱۸: وبینار و شرکت‌کنندگان (`/leads/webinars`):** لیست وبینارها، جزئیات با ۴ تب، قیف کوچک تبدیل، ایمپورت حضور و تبدیل حاضران به لید با تفکیک تکراری‌ها.

### فضای کاری ۳: اجرا و دانش (صفحات ۱۹ تا ۲۶)
- [x] **صفحه ۱۹: مدیریت تسک‌ها (`/work/tasks`):** سوییچ تسک‌های من/تیم، سوییچ لیست/برد، لیست دسته‌بندی‌شده زمانی، فیلد ثبت سریع بالا، کشوی جزئیات با ساب‌تسک و کامنت با @.
- [x] **صفحه ۲۰: تقویم شمسی (`/work/calendar`):** شبکه ماه/هفته شمسی با شروع شنبه، کشیدن رویداد برای تغییر تاریخ، کشوی جزئیات، نوار چندروزه کمپین‌ها، نمای روزانه در موبایل.
- [ ] **صفحه ۲۱: مدیریت تجهیزات (`/work/equipment`):** نمای «کمبودها (پیش‌فرض)» با هشدار کمتر از ۳ روز تا رویداد؛ جدول «همه تجهیزات»؛ قالب‌های آماده. *(برنامه‌ریزی‌شده در فاز ۳)*
- [ ] **صفحه ۲۲: صورتجلسات (`/work/meetings`):** لیست جلسات، صفحه مطالعه با عرض ۸۰۰ پیکسل، فرم جلسه با جدول اقدامات، دکمه «تبدیل اقدامات به تسک»، تاریخچه نسخه‌ها. *(برنامه‌ریزی‌شده در فاز ۴)*
- [ ] **صفحه ۲۳: دستورالعمل‌های استاندارد (`/work/sops`):** لیست کارتی، صفحه مطالعه ۸۰۰ پیکسلی، مراحل و چک‌لیست، تاریخچه نسخه‌ها، دکمه «ساخت تسک از SOP»، استایل چاپ تمیز. *(برنامه‌ریزی‌شده در فاز ۵)*
- [ ] **صفحه ۲۴: سامانه آموزش (`/work/learning`):** تب‌های کتابخانه، آموزش‌های من، پیشرفت تیم؛ پلیر ویدیو با کنترل سرعت و ذخیره زمان توقف، تخصیص آموزش به پرسنل. *(برنامه‌ریزی‌شده در فاز ۶)*
- [ ] **صفحه ۲۵: صندوق ایده‌ها (`/work/ideas`):** فیلد ثبت سریع، رأی‌گیری یک‌کلیکی برگشت‌پذیر، تأیید/رد توسط مدیر، تبدیل به تسک، ثبت نتیجه اجرای ایده. *(برنامه‌ریزی‌شده در فاز ۷)*
- [ ] **صفحه ۲۶: گزارش فعالیت (`/work/activity`):** فیلتر نقش (مدیر همه، پرسنل فقط خود)، کارت‌های شاخص، جدول مقایسه پرسنل، فید زنده فعالیت‌ها با لینک، خروجی اکسل. *(برنامه‌ریزی‌شده در فاز ۸)*

### بخش تنظیمات (صفحات ۲۷ تا ۲۹)
- [x] **صفحه ۲۷: کاربران و نقش‌ها (`/settings/users`):** جدول کاربران با آخرین ورود، کشوی دعوت، تغییر نقش، دیالوگ تأیید غیرفعالسازی، ماتریس دسترسی نقش‌ها با چک‌باکس.

- [ ] **صفحه ۲۹: اتصال وردپرس (`/settings/wordpress`):** کارت وضعیت اتصال، تولید کلید API با باطل شدن قبلی، راهنمای راه‌اندازی، جدول نگاشت فیلدها، لاگ ردشده‌ها. *(برنامه‌ریزی‌شده در فاز ۹)*

## ۲. چک‌لیست الزامات غیرعملکردی، امنیت و فارسی‌سازی

- [x] کلمه عبور با الگوریتم قدرتمند Argon2id ذخیره می‌شود.
- [x] توکن دسترسی صرفاً در رم مرورگر است و در LocalStorage قرار ندارد.
- [x] رفرش‌توکن در کوکی امن HttpOnly با قابلیت ابطال خانواده توکن ارسال می‌شود.
- [x] کارشناس فروش به هیچ عنوان نمی‌تواند لیدهای سایر همکاران را مشاهده کند.
- [x] نقش کارفرما به درخواست‌های تغییر دهنده اطلاعات (POST/PATCH/DELETE) دسترسی ندارد.
- [x] شماره تماس لیدها برای کاربران غیرمدیر به صورت `۰۹۱۲***۴۵۶۷` ماسک می‌شود.
- [x] کوئری‌ها کاملاً از طریق Prisma پارامتریزه شده و خطر تزریق SQL وجود ندارد.
- [x] زبان فارسی و جهت راست‌به‌چپ (`dir="rtl"`) در تمام صفحات رعایت شده است.
- [x] فونت بومی وزیرمتن بدون نیاز به اینترنت بارگذاری می‌شود.
- [x] تقویم شمسی به صورت دقیق در ۱۱٬۳۲۳ روز متوالی تست و تایید شده است.
- [x] کلیه مبالغ با جداکننده هزارگان و ارقام فارسی همراه با پسوند «تومان» یا «ریال» نمایش می‌یابند.
- [x] درصدها با یک رقم اعشار (`۲۳٫۵٪`) و علائم مثبت و منفی نمایش داده می‌شوند.
- [x] شاخص‌های CPL و CAC از قاعده «کمتر بهتر است» با رنگ سبز برای کاهش تبعیت می‌کنند.
- [x] سه حالت استاندارد اسکلتون، حالت خالی با دکمه اقدام، و خطا با دکمه تلاش مجدد در صفحات رعایت شده است.
